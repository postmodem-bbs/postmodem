Postmodem
Features Run it Develop Brand GitHub

A modern bulletin board in the tradition of phpBB2 “modified by Przemo”: batteries included, every battery removable, trivially self-hosted. Accessible, themeable, extensible, works without JavaScript, and ships as one Docker image.

Run it in one command Source on GitHub

0.1.0 is an early preview, not ready for production. It is already a usable board, but data formats may still change before 1.0. Migrations carry a board forward; there is no downgrade. See the release notes.

Run it

Solo

One container, SQLite, data in a named volume.

$ docker run -d --name postmodem \
    -p 8080:8080 -v postmodem-data:/data \
    --read-only --tmpfs /tmp \
    ghcr.io/postmodem-bbs/postmodem:0.1

Stack

Postgres, Caddy with automatic HTTPS, several web replicas.

$ cd deploy
$ docker compose up -d

See compose.yaml and CONTAINERS.md.

Try the demo

Fill an empty board with demo content, then sign in as a demo member.

$ docker exec postmodem \
    /nodejs/bin/node /app/postmodem.js \
    seed-demo

Develop

With Docker only

The board on :5173 with live sync, Postgres, and Mailpit on :8025. Also opens as a Dev Container.

$ docker compose \
    -f deploy/dev/compose.dev.yaml \
    up --build --watch

With Node 24 and pnpm 12

SvelteKit, TypeScript, SQLite or Postgres. Every commit is signed off (DCO).

$ pnpm install
$ pnpm dev
$ pnpm check
